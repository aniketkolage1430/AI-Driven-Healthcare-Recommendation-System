AI-Driven Healthcare Recommendation System
📌 Overview

This is an AI-based healthcare recommendation system developed using Python, Flask, and Machine Learning. The project predicts diseases based on symptoms and provides healthcare recommendations.

🚀 Features
Disease Prediction
Symptom Analysis
Healthcare Recommendations
User-Friendly Interface
Machine Learning Integration
🛠️ Technologies Used
Python
Flask
HTML, CSS, JavaScript
Scikit-learn
Pandas
NumPy

⚙️ Installation
Clone Repository
git clone https://github.com/your-username/AI-Driven-Healthcare-Recommendation-System.git
Install Requirements
pip install -r requirements.txt
Run Project
python app.py

Open browser:

http://127.0.0.1:5000/
